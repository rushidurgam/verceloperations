# ☁️ Hello from the Cloud — Vercel Demo

A beautiful, zero-dependency static site built for a **cloud computing workshop**. Students fork, deploy, and see auto-redeploy — all in under 2 minutes.

---

## 🚀 Student Steps

1. **Fork this repo** — click "Fork" at the top-right of this GitHub page.
2. **Go to [vercel.com](https://vercel.com)** and sign in with your GitHub account.
3. Click **Add New → Project**, then **Import** your forked repo.
4. Click **Deploy** — no settings need to change. Vercel auto-detects it as a static site.
5. In GitHub, open `index.html`, find the line that says **`YOUR NAME HERE`**, change it to your actual name, and commit. Watch Vercel automatically redeploy! 🎉

---

```
├── style.css    ← Dark theme, glassmorphism, animations
├── script.js    ← Live clock (purely cosmetic)
└── README.md    ← This file
```

## ✅ Why This Works on Vercel With Zero Config

- **No build step** — plain HTML/CSS/JS, nothing to compile.
- **No `package.json`** — Vercel's "Other" framework preset serves `index.html` directly.
- **No dependencies** — Google Fonts loaded via CDN, everything else is vanilla.
